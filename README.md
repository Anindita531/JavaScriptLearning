📘 JavaScriptLearning

A curated repository for learning JavaScript from basics to advanced topics. Includes interactive examples, exercises, and mini-projects to practice and reinforce concepts.

🧠 Overview

This repository is structured to help beginners and intermediate learners:

Understand core JavaScript concepts

Practice hands-on examples

Learn modern JavaScript features (ES6+)

Explore DOM manipulation, events, and asynchronous programming

Build small projects for practical experience

📂 Repository Structure
JavaScriptLearning/
│
├── 01-basics/                 # Introduction and basic syntax
├── 02-variables/              # Variables and declarations
├── 02.2DataTypes/             # JavaScript data types
├── 03-conditions/             # If-else and conditional statements
├── 04-loops/                  # Looping constructs
├── 05-functions/              # Function declarations and usage
├── 06-DOM/                    # DOM manipulation
├── 07-eventhandle/            # Event handling in JS
├── 08-json-data/              # Working with JSON
├── 09-Storage/                # localStorage and sessionStorage
├── 10-Asynchronous/           # Callbacks, Promises, Async/Await
├── 12Event Bubbling/          # Event propagation concepts
├── Advance/                   # ES6 Modules, Import/Export
├── JQuery/                    # jQuery basics
├── JavascriptTutorials/       # Guided tutorials
├── ProjectSelf/               # Self-practice projects
├── Projects/                  # Mini practice projects
├── Synchronous/               # Synchronous JS examples
├── event.stopPropagation/     # Event methods examples
├── js-practice/               # Miscellaneous practice
└── operators/                 # JavaScript operators
